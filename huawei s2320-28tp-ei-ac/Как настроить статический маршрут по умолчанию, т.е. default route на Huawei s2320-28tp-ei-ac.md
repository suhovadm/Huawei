1)	system-view  

Первый вариант: ip route-static 0.0.0.0 0 192.168.99.254   
Второй вариант: ip route-static 0.0.0.0 0 10.0.0.254  

0.0.0.0 0 <--- Куда мы хотим попасть, в нашем случае означает "вся сеть", или "через всю сеть".  
192.168.99.254, или 10.0.0.254 <--- Через что мы хотим туда попасть, т.е. шлюз.  

2)	Как проверить?  

display ip routing-table 0.0.0.0 или просто  
display ip routing-table  

в поле next-hop будет указан наш шлюз и тип STATIC.
