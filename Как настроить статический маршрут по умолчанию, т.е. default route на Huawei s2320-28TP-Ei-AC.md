Как настроить статический маршрут по умолчанию, т.е. default route на Huawei s2320-28TP-Ei-AC ?  

1)	system-view  
ip route-static 0.0.0.0 0 192.168.99.254  

2)	Как проверить?  

display ip routing-table 0.0.0.0 или  
display ip routing-table  

в поле next-hop будет указан наш шлюз и тип STATIC.
